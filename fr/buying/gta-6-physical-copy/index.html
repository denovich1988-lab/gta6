    GTA 6 en version physique : y a-t-il un disque ?

    La version physique de GTA 6 n'a pas de disque : la boîte contient un code de téléchargement de la Standard Edition. Stockage, revente, cadeau : ce qui change.

    Statut
    Confirmé

    Réponse rapide

    • Les exemplaires en boîte de GTA 6 contiennent un code de téléchargement, pas un disque.
    • Seule la Standard Edition est vendue en boîte ; l'Ultimate Edition n'existe qu'en numérique.
    • Un exemplaire en boîte demande le même téléchargement, jusqu'à 212 Go.
    Sur cette page 3
    1. Ce qu'est la version boîte
    2. Ce que cela change pour vous
    3. Pourquoi acheter la boîte malgré tout

    GTA 6 a bien une édition physique, mais elle ne contient pas de disque. La boîte renferme un code à saisir sur la boutique PlayStation ou Xbox, puis le jeu se télécharge comme n'importe quel achat numérique.

    Ce qu'est la version boîte

    Version boîte Version numérique
    Édition Standard uniquement Standard ou Ultimate
    Ce que vous recevez Un code de téléchargement Une licence sur la boutique
    Taille du téléchargement Jusqu'à 212 Go Jusqu'à 212 Go
    Fonctionne sans lecteur de disque Oui Oui
    Bonus de précommande avant le 20 novembre 2026 Oui, sur le même code Oui

    Ce que cela change pour vous

    • Stockage : la version boîte ne fait gagner aucune place. Voir la taille de GTA 6.
    • Internet : il vous faut une connexion pour télécharger le jeu.
    • Revente et prêt : un code déjà utilisé ne peut pas être cédé. Seul un code scellé et inutilisé a une valeur à la revente.
    • Cadeau : la version boîte reste le moyen le plus simple d'offrir le jeu à quelqu'un.

    Pourquoi acheter la boîte malgré tout

    • Vous préférez payer en magasin ou avec une carte cadeau.
    • Vous voulez quelque chose à emballer.
    • Une enseigne propose un meilleur prix que la boutique de la console.

    Si aucune de ces raisons ne vous concerne, l'achat numérique donne le même jeu en moins d'étapes. Pour les différences entre les éditions, voir prix et éditions de GTA 6.

    Questions fréquentes

    GTA 6 aura-t-il un disque ?

    Non. L'édition physique est une boîte qui renferme un code de téléchargement.

    Peut-on revendre une version physique de GTA 6 ?

    Seulement tant que le code n'a pas servi. Une fois utilisé, le jeu est lié au compte en question.

    GTA 6 fonctionne-t-il sur une PS5 sans lecteur de disque ?

    Oui. Le jeu étant un téléchargement dans toutes ses versions, il fonctionne sur les consoles numériques.
