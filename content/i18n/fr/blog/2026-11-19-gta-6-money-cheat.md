**Le code argent de GTA 6 est Haut, Droite, Bas, Gauche, Haut, Gauche, Bas, Droite.** Il ajoute 250 000 $. Plusieurs guides de lancement rapportent le même code ; Rockstar n'a pas publié de liste officielle, et nous le testerons de nouveau dans le jeu sorti.

## Comment utiliser le code argent

1. Terminez l'histoire principale. Les codes se débloqueraient après le générique de fin.
2. Sauvegardez votre partie, car un code actif désactive la sauvegarde.
3. En mode libre, appuyez sur **Haut sur la croix directionnelle** pour ouvrir le téléphone.
4. Maintenez **L1 + R1** sur PS5 ou **LB + RB** sur Xbox Series X|S.
5. Saisissez : **Haut, Droite, Bas, Gauche, Haut, Gauche, Bas, Droite**.

Le code n'utilise que la croix directionnelle : il est donc identique sur les deux consoles.

## Ce qu'il vous coûte

| Effet | Tant qu'un code est actif |
|---|---|
| Sauvegarde | Désactivée |
| Trophées et succès | Désactivés pour la session |
| Progression de l'histoire | Aucun effet, puisque l'histoire est déjà terminée |

## Pourquoi il n'est pas disponible plus tôt

GTA 5 n'avait aucun code argent. GTA 6 en a un, mais le verrouille derrière la fin du jeu : impossible de s'en servir pour court-circuiter l'économie de l'histoire. C'est une récompense pour le mode libre.
