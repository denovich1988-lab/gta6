    GTA 6 Physical Copy: Is There a Disc?

    The GTA 6 physical copy has no disc. The box contains a download code for the Standard Edition. What that means for storage, resale and gifting.

    Status
    Confirmed
    Updated
    November 19, 2026
    Read
    1 min
    By
    GTA6Box team

    Quick answer

    • Boxed copies of GTA 6 contain a download code, not a disc.
    • Only the Standard Edition is sold in a box; the Ultimate Edition is digital only.
    • A boxed copy needs the same download of up to 212 GB.
    On this page 3
    1. What the boxed copy is
    2. What this changes for you
    3. Why buy the box at all

    GTA 6 has a physical edition, but there is no disc in it. The box holds a code that you redeem in the PlayStation or Xbox store, and the game then downloads like any digital purchase.

    What the boxed copy is

    Boxed copy Digital copy
    Edition Standard only Standard or Ultimate
    What you receive A download code A store licence
    Download size Up to 212 GB Up to 212 GB
    Works without a disc drive Yes Yes
    Pre-order bonus before November 20, 2026 Yes, on the same code Yes

    What this changes for you

    • Storage: a boxed copy saves no space. See GTA 6 file size.
    • Internet: you need a connection to download the game.
    • Resale and lending: a redeemed code cannot be passed on. Only a sealed, unused code has resale value.
    • Gifting: a boxed copy is still the simple way to give the game to someone.

    Why buy the box at all

    • You prefer to pay in a shop or with a gift card.
    • You want something to wrap.
    • A retailer has a better price than the console store.

    If none of those apply, buying digitally is the same game with fewer steps. For edition differences, see GTA 6 price and editions.

    Frequently asked questions

    Will GTA 6 have a disc?

    No. The physical edition is a box with a download code inside.

    Can I resell a GTA 6 physical copy?

    Only while the code is unused. Once it is redeemed, the game is tied to that account.

    Does GTA 6 work on a PS5 without a disc drive?

    Yes. Because the game is a download on every version, it works on digital consoles.
